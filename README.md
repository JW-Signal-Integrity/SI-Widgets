# SI-Widgets

A growing collection of lightweight, **single-file web tools** — no build step,
no framework, no tracking. Each widget is one self-contained HTML file that
runs entirely in the browser. All tools are in English.

## Tools

| Widget | Path | Description |
|--------|------|-------------|
| [mil ↔ mm Converter](tools/mil-mm-converter.html) | `tools/mil-mm-converter.html` | Convert between mil (thou) and millimetres in both directions. Results are rounded to 2 decimals and copied to the clipboard automatically. |

More widgets coming soon.
